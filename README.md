# 💕 Presente de aniversário

Um site romântico de página única feito como presente de aniversário.

## Arquivos

- `index.html` — estrutura e textos
- `style.css` — visual e responsividade
- `script.js` — animações e interações
- `images/` — coloque aqui as fotos de vocês

## Como personalizar

Abra o `index.html` e substitua os textos fictícios pelas suas próprias histórias.

Para colocar uma foto, você pode trocar o bloco:

```html
<div class="photo-placeholder">
```

por:

```html
<img src="images/foto1.jpg" alt="Nós dois">
```

e depois ajustar o CSS se quiser.

## Publicar no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie `index.html`, `style.css`, `script.js` e a pasta `images`.
3. Vá em **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/root`.
6. Salve.
7. O GitHub vai gerar o endereço do site.

## Dica

O resultado fica muito mais pessoal quando você troca os textos genéricos por:
- apelidos;
- datas importantes;
- histórias que só vocês conhecem;
- pequenas manias dela;
- frases que ela costuma falar;
- fotos de momentos específicos;
- uma carta escrita com suas próprias palavras.
